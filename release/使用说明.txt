X4: Foundations 舰船 Mod 辅助工具
=====================================

【环境要求】
Windows 10/11  +  Python 3.9 或更高版本
安装 Python 时务必勾选 "Add Python to PATH"。
本工具只用 Python 标准库，不需要 pip 安装任何依赖。

【启动】
1. 把压缩包解压到任意目录（路径含中文也可以）。
2. 双击「启动工具.bat」。
3. 稍等片刻，浏览器会自动打开 http://127.0.0.1:8765
4. 关闭黑色命令行窗口即停止服务。

【首次使用（重要）】
1. 打开页面顶部「游戏解包」选项卡。
2. 在「当前解包根」填写你的 X4 游戏解包目录（含 assets、index、libraries 等文件夹的那一层）。
3. 保存设置，然后关闭窗口、重新双击「启动工具.bat」使配置生效。
4. 之后在各功能选项卡里选择「目标 mod」目录即可开始使用。

【功能简介】
- 舰船模板：以现有舰船为模板，改名生成新舰船全套 XML（macro、wares、t 文本、index 注册等）。
- 装备编辑：修改已有装备数值，支持弹药、尾焰、爆炸等。
- Dock 复用：复用现有 dock 的模型，只改 XML（waypoint 整体替换、dockingbay 组名）。
- 模型同步：把 Blender 导出的模型/组件结构同步进 mod。
- 解包 / Diff：解包游戏与 mod 数据、对比文件差异。

【安全说明】
- 服务只监听本机 127.0.0.1，不对外网开放，不需要联网。
- 覆盖宏/组件前会自动备份到「解包根\_x4sb_backup」（可在配置中改路径）。
- 所有配置保存在工具目录下的 builder_config.json，仅本机有效。

【常见问题】
- 双击没反应 / 提示未检测到 Python：重新安装 Python 并勾选 Add to PATH，或在命令行执行 python --version 确认。
- 提示服务启动超时：多半是 8765 端口被占用，关闭占用程序（或之前的工具窗口）后重试。
- 浏览器没自动打开：手动访问 http://127.0.0.1:8765
